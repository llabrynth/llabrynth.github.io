02 트러블슈팅

에러 없이 짧은 코스만 나오던 문제

  • 39 → 15%목표 거리 대비 평균 오차
  • 7 → 0건거리 보정 건너뜀 경고
문제
서버는 정상 응답하는데 추천 코스가 목표 거리보다 눈에 띄게 짧음
해결
로그 경고로 운영 DB의 노선 테이블이 빈 것을 찾아 데이터를 다시 적재

측정: 같은 조건의 추천 10건으로 목표 거리와 실제 코스 거리를 비교

해결 과정

증상
추천 10건의 코스가 목표 거리와 평균 39% 차이. 응답은 모두 정상
단서
서버 로그에 "거리 보정을 건너뛴다" 경고 7건
원인
운영 DB의 자전거길 테이블이 0건
조치
13노선을 다시 적재해 운영 DB에 한 트랜잭션으로 반영
확인
같은 조건으로 다시 추천해 재측정. 차이 15%, 경고 0건

갈라지는 자전거길이 직선으로 이어지던 문제

  • 151.4 → 94.7km한강종주 저장 길이
  • 726.6km없앤 직선 (5개 노선 합계)
문제
갈라지는 노선을 한 줄로 저장해, 갈래 사이가 직선으로 이어지고 길이가 늘어남
해결
팀원의 변경 제안을 검토해 노선 형상을 여러 갈래(MultiLineString)로 변경

측정: 운영 DB의 노선 길이와, 같은 좌표를 한 줄로 이었을 때의 길이를 비교
